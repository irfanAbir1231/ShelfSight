# Square logo templates

Place tightly cropped Square logo reference images in this directory.

Recommended starting set:

- `square_primary.png`
- `square_white_on_dark.png`
- `square_legacy.png`

Use clear PNG/JPEG/WebP images with at least 32 px on the shortest side. The
baseline matcher checks each product crop at multiple scales. These templates
are only for the prototype; the production model should use annotated real
shelf images.
